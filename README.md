# React + Vite Video Streaming App

A modern, responsive Video Streaming application built with **React** and **Vite**. This template provides a professional foundation for scalable web apps featuring fast development, premium icon integration, and a user-friendly interface. Hot Module Replacement (HMR) and ESLint rules are included for an efficient developer experience. 

---


## Features

- 🚀 **Powered by Vite:** Lightning-fast build and HMR for instant feedback.
- 🖥️ **Responsive Design:** Seamlessly adapts to desktops, tablets, and mobile devices.
- 🎬 **Video Streaming:** Stream high-quality video content with smooth playback.
- 🌟 **Premium Icons:** Uses [React Icons](https://react-icons.github.io/react-icons/) and supports [Phosphor Icons](https://phosphoricons.com/) for a visually appealing UI.
- 🔍 **Search & Filter Options:** Easily find videos by title, category, or tags.
- 🛠️ **Customizable Theme:** Switch between dark and light modes.
- 🔗 **Social Sharing:** Share videos across popular social platforms.
- ⭐ **Favorites & Playlists:** Save favorite videos and organize playlists.
- 📱 **Progressive Web App (PWA) Ready:** Add-to-home functionality for mobile devices.
- 🧑‍💻 **ESLint & Prettier:** Consistent code style and linting included.
- ⚡ **Fast Refresh:** Supports both Babel and SWC for optimal development experience.

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) v16+
- [npm](https://www.npmjs.com/) or [Yarn](https://yarnpkg.com/)

### Installation

```bash
git clone https://github.com/your-username/video-streaming-app.git
cd video-streaming-app
npm install
# or
yarn install
```

### Running in Development

```bash
npm run dev
# or
yarn dev
```
Visit [http://localhost:5173](http://localhost:5173) in your browser.

### Building for Production

```bash
npm run build
# or
yarn build
```

### Linting

```bash
npm run lint
# or
yarn lint
```

## Customization

- **Theme:** Modify or extend theme colors and settings in `src/theme.js` or your CSS framework config.
- **Plugins:** Switch between [`@vitejs/plugin-react`](https://github.com/vitejs/vite-plugin-react) or [`@vitejs/plugin-react-swc`](https://github.com/vitejs/vite-plugin-react-swc) in `vite.config.js`.
- **Icons:** Easily change icon packs in `src/icons/`.
